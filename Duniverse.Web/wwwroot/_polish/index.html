Polish pass, four small things

Throwaway page. Hover the cards below to compare the shimmer. Everything on the left is the old behaviour, put back by hand; everything on the right is what's in the code now.

1. Shimmer, once and settle

The spice light along a hovered card's rim used to loop forever at 2.5s. Leave the cursor parked and it keeps flickering next to whatever you're trying to read. Now it makes one pass out and back over 1.4s and stops. It fires again every time you re-enter the card, and it ends exactly where it started, so the settled state and the reduced-motion state look the same.

2. Resting input borders

An empty search field used to draw its box at 1.5:1 against its own fill, which is faint enough that the field read as a suggestion of a box rather than a box. The new token sits at 3.2:1, which clears the line for a control's outline. Focus still goes gold, and the jump from resting to focused is still obvious. Click into both to check.

3. A missing record joins the deep desert

Ask for a record id that doesn't exist and you used to get a bare card with two flat sentences, even though it's the same dead end the 404 already dresses as open sand. Both now run through one component, so a reader who hits one and then the other recognises the place. The 404 keeps its wording; the record miss names the id you asked for.

4. Dead template CSS, gone
